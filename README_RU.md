## Экраны

| Маршрут | Что | Кому |
|---|---|---|
| `/` | Живая карта: владение, щиты, бой, «проверено» | смотреть — всем, статус — хелпер+ |
| `/war-room` | **Штаб**: чат, общие тропы захвата, заметки, сводка | офицер+ |
| `/stats` | Статистика по королевствам | всем |
| `/nodes` | Таблица узлов + форма + панель королевств | смотреть — всем, правка — админ |
| `/links` | Редактор дорог | админ |
| `/team` | Аккаунты, инвайты, журнал | офицер+ |
| `/login`, `/join/[token]` | Вход и регистрация по инвайту | — |

`/map` ведёт на `/` (старая закладка).

### `/` — Живая карта (ежедневная работа)

Кто чем владеет, таймеры щитов, отметки боя, обновление владения в один тык
для хелперов и офицеров. Живое обновление по SSE (`/api/live` + `/api/map`).

**Выработку кристаллов вводить не нужно** — она считается сама, см. ниже.
**Карта уже введена**: чистая база поднимается с 231 узлом и 352 дорогами, всё
ничейное.

### `/war-room` — Штаб (офицер+)

Общая комната планирования: **чат + тропы захвата** на карте только для
чтения. Владение по-прежнему пишется только на `/`.

- **Чат** на сервере; пин к узлу — чип в сообщении (на карте **без** жёлтой
  обводки). «Набирает…» вживую, в БД не пишется.
- **Тропы:** короткий тык по чужому — кратчайший путь от королевства штаба;
  ещё раз по кончику — снять. Долгий тап / ПКМ — меню: в план / из плана,
  в чат, заметки (облачка). Удаление узла срезает его и **перепрокладывает**
  хвост, если обход ещё есть.
- **Общий план** на всех вкладках (SSE). Узел на нескольких тропах в сводке
  один раз. Админ задаёт **королевство штаба** (по умолчанию K6).
- **Сводка:** рога (город N ур → N; **ворота → 1**), аметист/сапфир /ч,
  иконки баффов. Справка — кнопка «?» справа.

### `/nodes` — Таблица узлов (правка — админ)

Ввод и правка объектов: название, координаты, тип, уровень, баффы, заметка.
Панель королевств (админ): номер, название, цвет, база. Переименование
**не теряет владение**.

### `/links` — Связи (админ)

Клик по узлу, потом по второму — поставить/снять дорогу; клик по линии —
удалить. Зум, пан, **Вписать**, **45°**, **Y↕**.

### Как читается карта

Узел — цветной кружок со значком внутри: цвет говорит, **чей** он, значок —
**что** это. Замок — город, дверь — врата, башня — турель, флаг — база
королевства, **корона — главный замок**, Трон в центре карты.

Подписи зависят от зума, иначе на общем плане они сливаются в серую кашу:

| Зум | Что подписано |
|---|---|
| вблизи | название и уровень (плюс таймер щита) |
| средний и общий план | только уровень |
| совсем далеко | значки (на широком виде — цвет территории) |

**Баффы** (кнопка на карте) переключают карту на другой вопрос: вместо «что
это» — «что это даёт». Значок узла меняется на значок баффа (мечи — атака, щит —
защита, сердце — HP), подпись — на процент, а узлы без баффов сжимаются в точку,
чтобы не мешали выбирать цель.

## Кристаллы

Два типа: **Amethyst** (фиолетовый) и **Sapphire** (синий). Выработка выводится
из типа объекта и его уровня, руками её вводить не надо:

| Уровень | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| В час | 60 | 120 | 240 | 360 | 480 |

- **Город** — аметистовая и сапфировая шахта, обе уровня самого города.
- **База королевства** — только сапфир 1 ур (60/ч), аметиста нет.
- **Врата, турель, главный замок** — шахт нет.

Уровень вне таблицы (в игре встречается Lv.6) показывается как `?`, а не как 0 —
такие узлы считаются отдельно в плашке «Выработка ?», чтобы итог не занижался
незаметно. Для них можно задать значение вручную кнопкой «вручную»; ручные
значения помечены `*`.

Когда выработка для старших уровней станет известна, правится одна таблица в
`lib/crystals.ts` — все узлы пересчитаются сами.

## Языки

EN / RU / AR, переключатель в шапке. Для арабского включается RTL. Выбор
хранится в cookie, при первом заходе берётся из языка браузера.

Словари — `lib/i18n.ts`. Русский там источник ключей, английский и арабский
типизированы под него, поэтому забытый перевод не соберётся.

## Телефон

Основной сценарий — правки прямо во время игры, поэтому:

- вместо широкой таблицы — карточки;
- форма ввода сворачивается, чтобы список был под рукой;
- сайдбар карты на телефоне открывается снизу;
- пинч-зум и тач-цели не меньше 40px;
- зум страницы отключён, чтобы два пальца тянули карту, а не интерфейс.

## Роли и доступ

| | гость | хелпер | офицер | админ |
|---|---|---|---|---|
| Карта, статистика, узлы — просмотр | ✓ | ✓ | ✓ | ✓ |
| Владение, щиты, бой, «проверено» | | ✓ | ✓ | ✓ |
| Штаб (чат + планирование) | | | ✓ | ✓ |
| Команда и приглашения | | | ✓ | ✓ |
| Правка узлов и дорог | | | | ✓ |

Регистрации нет: попасть внутрь можно только по одноразовой ссылке
`/join/<токен>`, живёт 7 дней и гаснет при использовании. Админ приглашает
офицеров и хелперов, офицер — только хелперов. В списке команды видно, **кто
кого пригласил**.

Офицер может отключить хелпера, админ — любого, кроме себя. Отключение
действует сразу. Все действия с аккаунтами пишутся в журнал на `/team`.

Первый вход: пока пользователей нет, `ADMIN_NICK` / `ADMIN_PASSWORD` из
`.env.local` создают админа. Дальше env не используется.

На входе и регистрации стоит Cloudflare Turnstile плюс лимит попыток. Без
ключей проверка отключается, локально всё работает.

## Данные

`db/schema.ts`:

- `kingdoms` — состав карты: номер, название, цвет. `id` — неизменный слот,
  на него ссылается владение, поэтому королевство можно переименовать.
- `nodes` — объекты карты. Уникальный индекс по `(x, y)`: один объект на клетку,
  это ловит повторный ввод того же города. `owner` — кто держит сейчас,
  `kingdom` — чья это база по замыслу карты.
- `edges` — дороги. Пара всегда хранится в порядке `aId < bId`
  (`normalizePair`), поэтому дубликат невозможен независимо от порядка кликов.
- `changes` — лог владения; `users`, `invites`, `audit_log` — аккаунты.
- `messages` — чат штаба (текст, ник, опциональный `nodeId`, время); «набирает…»
  только live
- `plan_settings` — за какое королевство штаб строит тропы
- `plan_paths` / `plan_path_nodes` — упорядоченные тропы захвата
- `plan_notes` — заметки офицеров на узлах

Статика карты (узлы, дороги, королевства) лежит в `db/seed-data.ts` и
заливается в пустую базу сама. Поправив карту через UI, заморозить обратно:

```bash
npm run db:export-seed
```

## База

`warzone.db` рядом с проектом, путь меняется через `SQLITE_PATH`. Файл в git не
попадает — карта восстанавливается из сида, владение живёт только в базе.
Бэкап — копия файла.
